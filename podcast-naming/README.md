## Note on GitHub Pages

GitHub Pages is intentionally **not** enabled for this repository.

A Pages site published from a private repo is still publicly reachable on
Free, Pro, and Team plans — the repo stays private, the site does not.
Access-controlled Pages, where only organisation members can load the URL,
is a GitHub Enterprise Cloud feature and requires the repo to live in an
Enterprise Cloud organisation.

Until then, enabling Pages here would put this page on the open internet.
Share it as a private link instead.
